Este projeto foi feito pelos alunos Bernardo Terra, Samuel Ferreira e Renan Ferreira da 33ª turma de Engenharia de Computação da Univerdidade Federal de Rio Grande (FURG)
O projeto consiste em um jogo criado e desenvolvido usando a biblioteca de Python especializada para jogos retro chamada Pyxel, avaliando os conteúdos de lógica e 
algoritmos ensinados durante as aulas.
O nome do jogo é Space Raiders, sendo um jogo do gênero Shoot 'Em Up ou Danmaku, que consiste no jogador avançar por várias hordas de inimigos enquanto desvia de 
projéteis, desafiando as habilidades do jogador com movimentos e reações rápidas

--- CONTROLES ---

W A S D ou ⭠ ⭢ ⭡ ⭣ -- Movimentação
Espaço -- Atirar


--- CONCEITOS STEAM ---

Ciência:
Foi utilizado equações de velocidade, onde um valor fixo reduzia ou aumentava os valores posicionais dos corpos, como os da nave do jogador e dos inimigos.

Tecnologia:
Foi utilizado o Visual Studio Code como IDE principal para programação, escolhida pela familiaridade dos membros e pela interface síncrona com o GitHub. 
O Trello foi escolhido como programa para organizar ideias e tarefas entre membros

Engenharia:
O código foi escrito usando da biblioteca Pyxel de Python, própria para criação de jogos

Artes:
Todos os sprites do jogo foram feitos pelos membros utilizando do próprio editor de gráficos do Pyxel.

Matemática:
Matemática básica, como na adição e subtração de valores, por exemplo nas vidas de inimigos e do jogador, na barra de experiência e na pontuação. 
Matrizes também foram necessárias para a renderização gráfica, buscando os sprites guardados na memória.
